# BreakCycle v0.9 — Interactive Calendar Day Breakdown

Upload `index.html` and `.nojekyll` to your GitHub Pages repository root.

Click or keyboard-select (Tab + Enter/Space) any calendar date to view its scheduled income, bill and loan repayment allocations, planned savings, and net remaining **for that date only**. All events are itemized. The selected date is highlighted; navigating between months selects the first day if the previous selection is outside the new month. The day breakdown uses the same event data as the calendar and dashboard.

**Financial caveats:** This is not a running account balance or confirmation of payment. A bill funded from a paycheck remains a future obligation until actually paid; allocating money is not paying it. Savings contributions are projections. Other everyday spending entered on the Dashboard is not included in daily event totals. Use fictional data while testing; information is stored in browser localStorage without encryption.
